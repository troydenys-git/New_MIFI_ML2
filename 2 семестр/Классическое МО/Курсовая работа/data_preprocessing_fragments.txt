
Фрагменты из документа: Обработка данных перед машинным обучением

1. Общие принципы (стр. 5):
"Данные: сбор, очистка, разметка"

"Такая база должна быть очищена, стандартизирована по условиям эксперимента 
(например, нет смысла сравнивать соединения, которые устойчивы при разной ионной силе)."

2. Подготовка данных (стр. 6):
"Прежде чем использовать данное «болото» данных, они должны пройти процедуру 
упорядочивания данных, добавления к ним контекста, метаданных, добавления лейбла к таким данным, 
очистку, критический осмотр и т.д. Если кратко, то нужно обработать данные крайне полно, 
чтобы их можно было использовать."

3. Feature engineering (стр. 7):
"Скорее всего, придется векторизовать данные других типов – текст, картинки, структурные формулы"

"Проверяем масштабирование (scaling)"

4. Curated data (стр. 23):
"Очистка (нет дубликатов, неполных данных, банальных ошибок)
Оценка качества
Аннотация и т.д."

"Кроме того, необходимо делать labelled data: для понимания того, с чем мы работаем."

5. Представление данных (стр. 24):
"Перед нами стоит задача как перевести химические данные в массив данных."

6. Преобразование в признаки (стр. 6):
"Данные о структуре переводят в вектора известной постоянной длины (вектор-признак)."

7. Разделение данных (стр. 9):
"Имея набор данных (Data Set) неплохо бы часть этого набора данных отложить «про запас». 
Это нужно для того, чтобы проверить как работает данная тренировочная модель."

8. Масштаб и качество данных (стр. 6):
"Данные должны быть структурированными, однородными, с известной погрешностью."
