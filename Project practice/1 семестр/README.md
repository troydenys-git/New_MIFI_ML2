## Система мониторинга животных

### Проблема (Контекст и Актуальность)

Мониторинг животных в лесу нужен для сохранения биоразнообразия, изучения экосистем, управления ресурсами, предотвращения конфликтов с людьми и борьбы с браконьерством, а также для научных исследований и оценки влияния климатических изменений. Отслеживание помогает понять миграции, численность, состояние здоровья видов и оперативно реагировать на угрозы, например, выявлять очаги болезней или хищников, опасных для домашних стад. 

Бизнес, связанный с выращиванием различных агрокультур, или разведением животных может быть заинтересован в мониторинге с точки зрения оповещения о животных-вредителях, которые могут уничтожить продукт.

---

### 2. Решение 

Проведение мониторинга животных с помощью фотоловушек. Оповещение заинтересованных лиц о виде, количестве животных.

#### Технические компоненты

| Элемент Системы | **Входные Данные / Триггер** | **Функция / Реализация IT-Решения** |
| :--- | :--- | :--- |
| **Детекция Животных** | Постоянно работающие **фотоловушки** (с передачей по 4G/спутниковой связи). | **Модель машинного обучения (SAM3)**, обученная на изображениях местных животных (барсуки, обезьяны, еноты, кабаны). Задача: **Детекция и классификация объектов** (object detection). |
| **Визуализация и Анализ** | Фотоловушки | Результаты детекции: **название животного, количество особей**. |
| **Автоматическое Оповещение** | Фотоловушки | **Автоматический триггер** (Telegram/Email-бот) для немедленного оповещения егерей|
